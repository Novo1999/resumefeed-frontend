The resume feed project is about a site where users can come and then see peoples uploaded resume in a feed and then they can react or review peoples resume and rate and review them. this is the high level overview of the project. The product should have a professional looking landing page.
It should have a marketing pitch that should suppose to attract users to use this product and build a community to make sure people can be useful to each other by sharing constructive criticism
and ratings to the resume.

The tech stack I am trying to use here:

- Supabase Auth
- Express & TypeORM with POSTgreSQL in the backend, Supabase Storage (bucket) for resume files and images of users
- The nextjs client uses redux and rtk and shadcn

I am currently focusing on the authentication part. The auth should be done using supabase auth.
